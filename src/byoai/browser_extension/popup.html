Checking Shield

Start it with byoai-shield. To have it start every time you log in, run byoai-shield --install-login-item.

Shield notes that you sent a message, to which app, when, and how long it was. It does not read what you wrote. Read exactly what is recorded

To accept records only from this install, start Shield with BYOAI_SHIELD_EXTENSION_IDS=<id>.

Copies the version, the state above and when each app was last noted. It never includes anything you wrote.
