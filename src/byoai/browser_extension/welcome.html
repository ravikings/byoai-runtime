Shield notes that you sent a message. It never reads what you wrote.

Please read this before turning it on. Nothing is recorded until you agree.

Where it watches

Only when you send a message on claude.ai, chatgpt.com (and chat.openai.com), gemini.google.com or copilot.microsoft.com. No other site.

What it records

  • which app you used,
  • when you sent the message,
  • how many characters it was.

That is all. The message text is counted in the page and thrown away. It is never stored and never sent anywhere.

Where it goes

To the Shield program running on this computer (127.0.0.1). The extension has no other destination: no server of ours, no analytics, nothing over the internet. What Shield does with its own record is described in its documentation.

You need Shield running

This extension is the browser side of Shield, a separate program you install on this computer (byoai-shield). Without it, nothing is recorded; a few messages are held for a short while and then dropped.

Turning it off

Turn capture off any time from the toolbar popup. Turning it off also removes anything still waiting to be sent. Read the full privacy notice.

Choosing "Not now" leaves the extension installed but doing nothing. You can change your mind from the popup.

Capture is on

Start Shield with byoai-shield if it isn't running. Open the extension popup any time to see whether it is working, or to turn capture off. You can close this tab. Pages that were already open need a reload before they are covered.

Capture is off

Nothing will be recorded. To turn it on later, open the extension popup and choose "Review and turn on". You can close this tab.
